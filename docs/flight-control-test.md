# 飞行切换实验说明（待硬件验证）

本版本 USART2 使用 115200 8N1，命令必须以 CRLF 结束。此前 README 中单字符 `1/2/3/4/6/8` 的说明不适用于本版本固件；它们均返回 `error`。USART6/OpenMV 通信保留，但 USART2 不再提供启动 OpenMV 命令。

| 命令 | 动作 |
| --- | --- |
| `0\r\n` | 采集 ADC1 电池分压并返回 `Battery:x.xxV\r\n`，采样失败返回 `Battery ADC error\r\n`；这是电压而非剩余电量百分比 |
| `1 1620\r\n` 至 `4 1620\r\n` | 分别保存并立即输出舵机 1～4 的起飞脉宽（μs）；上升与降落锁定期拒绝 |
| `6 1620\r\n` 至 `9 1620\r\n` | 分别保存舵机 1～4 降落脉宽，不立即输出；监测期间拒绝修改 |
| `5\r\n` | IMU 校准完成后手动进入等待发射，并把四路 PWM 切到起飞预设；飞行中或降落切换后的五秒保持期内不能重新布防 |

有效命令回复 `ok`，非法格式/范围回复 `error`；响应可能因当前非阻塞串口 TX 忙而丢失，应以状态和实际 PWM 验证。上电四路初始输出由 `SERVO_DEFAULT_PULSE_US=1620` 决定；`SERVO_1_TAKEOFF_PULSE_US`～`SERVO_4_TAKEOFF_PULSE_US`、`SERVO_1_LANDING_PULSE_US`～`SERVO_4_LANDING_PULSE_US` 是分别独立配置的编译时预设，当前八个值均为 1620 μs。只有成功布防才会自动输出起飞预设；布防前的 `1–4` 手动调试指令仍会立即更新对应 PWM，是初始位置的例外。`1–4` 与 `6–9` 可分别覆盖起飞、降落值，互不覆盖；覆盖值保留至复位。代码使用 `SERVO_MIN_PULSE_US=1000`、`SERVO_MAX_PULSE_US=2000` 检查串口及编译时预设；这是原工程已有的端点试验区间，**不是舵机或机构安全性认证**。必须先确认舵机型号、联杆行程和供电，并按实际安全范围缩窄配置，再连接机构测试。

从启动 PWM 的时刻计约 `FLIGHT_AUTO_ARM_MS=10000` ms，若尚在 F=0 且 IMU 已校准运行，自动进入 F=1、四路输出起飞预设，同时蜂鸣两声（每声约 150 ms，间隔约 150 ms）。现有上电三声提示与此区分；手动 `5` 提前布防不重复触发十秒自动提示。若十秒时 IMU 尚未校准成功，不鸣两声，待校准完成后再布防并提示；若 IMU 报错则不自动布防。两声只能表示布防成功，不代表发射检测成功或真正测量到了最高点。蜂鸣状态更新优先级为降落事件/电源按键、自动布防、上电提示；蜂鸣器不阻塞 IMU 处理。

主循环随 BMI088 陀螺仪 1000 Hz DRDY 更新姿态（加速度计 1600 Hz）；传感器 SPI 访问仍是有超时的同步访问，主循环不能保证无丢样。IMU 上电需静止完成 1000 个样本零偏校准。状态 F: 0 待命、1 等发射、2 已检测发射/等待姿态确认、3 已执行降落、4 IMU 故障。约每 200 ms 输出：ms(系统启动后的毫秒时基)、I(IMU 状态，2=运行)、e(IMU 错误)、R/P/Y(原有字段，十分之一度)、Xdeg/Ydeg/Zdeg(姿态解算的绕机体系 X/Y/Z 欧拉角，分别对应 Roll/Pitch/Yaw；单位度，保留一位小数)、A(加速度模长×100 m/s²)、G(角速度模长×100 rad/s)、C(发射候选)、T(发射后 ms)、V(是否发生切换)、B(蜂鸣)、S(四路舵机 PWM 是否有有效脉冲)、U(姿态更新累计)、O(陀螺仪过载累计)、E(SPI 错误累计)。Xdeg/Ydeg/Zdeg 是 R/P/Y 的可读角度形式，不是飞行位置坐标或高度；只有随校准完成后姿态更新才有效，且偏航角无磁力计绝对方向参考、可能漂移。相邻 U 差值可用于评估实际更新率；日志频率不足以捕获每次 1 ms 姿态变化，记录时请配合视频与 ms 时基。F=3 表示已经触发降落阶段；降落 PWM 保持 `FLIGHT_LANDING_HOLD_MS=5000` ms 后四路比较值归零（S=0），不再发送有效舵机控制脉冲。**这不是切断舵机电源，也不保证具体舵机卸力；需实测验证堵转电流。**重新成功布防会恢复四路起飞 PWM。切换只触发一次，蜂鸣独立持续约 3000 ms，主循环不会为蜂鸣停顿。

**重要：V 表示镖头朝下的姿态判定触发，不是实际最高点测量。** 发射门控：加速度模长达到 `FLIGHT_LAUNCH_ACCEL_MPS2=13.0f` m/s² 并持续 `FLIGHT_LAUNCH_CONFIRM_MS=6U` ms；两项均为 `main.c` 中可调整的编译时宏。手抛峰值/持续时间不足可能漏检，镖架晃动可能误触发。进入 F=2 后，仅在新姿态更新上使用原始 `roll_deg`（即 Xdeg 的未舍入值）：先见负值，再见正值，过零后第一帧正值算第 1 次，连续 `FLIGHT_ROLL_POSITIVE_SAMPLES=5U` 次严格大于零才切换；非正值会打断确认，后续再次负→正可重试。F=2 无 150 ms 最短等待、600 ms 自动切换或监测超时；一直未满足条件时持续输出起飞 PWM，也不会启动五秒停脉冲。IMU 故障仍进入 F=4，保持当前 PWM，不自动切换或断电。角度与实际轨迹顶点并无必然同步关系；必须在无危险载荷台架上验证触发效果。切换满五秒后可重新发送 `5` 布防，请勿在人或机构运动区域附近操作。

测试顺序（不要在人员附近抛飞镖）：

1. 不装危险载荷、断开或约束舵机联杆，检查供电、共地、机构安全脉宽。构建固件并经授权烧录；上电静置，核对四路初始输出均为 1620 μs。发送 `0\r\n`，确认返回 `Battery:x.xxV`；对照万用表核对电压与分压比，不能按电压直接推断电量百分比。
2. 不发送 `5`，等约十秒及 IMU 就绪，确认听到两声、F=1 且四路输出切到起飞预设。为确认初始/起飞不同阶段，可在安全台架上暂时将一个起飞宏改为经机械验证的不同脉宽并重新编译：十秒前仍应输出 1620 μs，两声后才改变。另一次复位测试 I=2 后十秒前发送 `5\r\n`，确认立即布防且十秒处不重复鸣两声。需要时用 `1–4` 和 `6–9` 测试独立预设。
3. 保持静止，确认 F=1 不触发。进行无载荷、安全的手抛试验，记录 ms、Xdeg、A、C、T、F、V、B、U、O、E 和视频姿态。若 F 不进入 2，重新评估发射阈值；若 F=2 不进入 3，检查发射后是否先见负角度且随后连续 5 次严格正角度。每 200 ms 一条的日志可能无法反映 5 次连续姿态更新，不能仅凭相邻日志推断判定结果。
4. 观测四路在事件后只切换一次，蜂鸣约三秒后关闭；用示波器确认从切换起约五秒时四路不再有有效 PWM 脉冲（S 从 1 变为 0），蜂鸣和舵机时长分别计时。测量舵机供电电流判断堵转是否缓解。测试过长/非法指令、IMU 未校准时发送 `5`、IMU 断线时不切换，以及 IMU 校准延迟超过十秒时不提前鸣两声。编译成功并不等于上述硬件验证已完成。

本功能仅修改用户代码及 IMU 状态数据，无需修改 CubeMX 引脚/定时器配置；再次生成代码时保留 `main.c` USER CODE 区域及独立的 IMU 文件。
